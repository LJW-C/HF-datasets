# IEEE DataPort Instructions

## Instructions

Download and extract the dataset files into one local directory. The dataset is provided in NumPy and JSON format. The main I/Q data file is `X.npy`, the fine-grained signal labels are stored in `y.npy`, and the corresponding class names are stored in `mode_names.json`. Additional labels are provided in `snr_db.npy` and `channel_profile.npy` for SNR-level and channel-profile analysis.

The expected dataset directory structure is:

```text
dataset_root/
|-- X.npy
|-- y.npy
|-- snr_db.npy
|-- channel_profile.npy
|-- mode_names.json
|-- channel_profiles.json
|-- meta.json
```

Use Python with NumPy to load the dataset:

```python
from pathlib import Path
import json
import numpy as np

dataset_root = Path("path/to/dataset_root")

X = np.load(dataset_root / "X.npy", mmap_mode="r")
y = np.load(dataset_root / "y.npy")
snr_db = np.load(dataset_root / "snr_db.npy")
channel_profile = np.load(dataset_root / "channel_profile.npy")

mode_names = json.loads((dataset_root / "mode_names.json").read_text(encoding="utf-8"))
channel_profiles = json.loads((dataset_root / "channel_profiles.json").read_text(encoding="utf-8"))

print(X.shape)
print(X.dtype)
print(mode_names[y[0]])
print(snr_db[0])
```

Each row of `X.npy` is one complex baseband I/Q vector with 2048 complex samples at a sampling rate of 6 kHz. For deep-learning frameworks that require real-valued tensors, convert each complex vector into a two-channel real-valued tensor:

```python
iq = X[0]
sample = np.stack([iq.real, iq.imag], axis=0).astype("float32")
```

Use `y.npy` as the primary classification target for 17-class HF digital-mode recognition. Use `snr_db.npy` to report performance at different SNR levels, and use `channel_profile.npy` to analyze performance under different HF fading-channel profiles. Recommended evaluation metrics include overall accuracy, macro-F1 score, balanced accuracy, per-SNR accuracy, and confusion matrices.

For standard experiments, split the data into training, validation, and test subsets using a stratified split that preserves the signal-mode and SNR distributions. Because samples are generated by random cropping from longer WAV recordings, users should clearly report the split strategy used in their experiments.

The dataset is synthetic and audio-derived. The signals were generated from Fldigi WAV recordings, converted to analytic complex baseband I/Q, resampled to 6 kHz, impaired with Watterson-style HF fading, randomized frequency and phase offsets, and complex AWGN. Therefore, the dataset is suitable for controlled HF digital-mode recognition experiments, but it should not be interpreted as direct over-the-air RF receiver data.
